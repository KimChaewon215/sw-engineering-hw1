## 팀 프로젝트 역할 분담 및 상세 수행 내용

### 팀원별 역할 총괄
| 팀원      | 담당 역할                                     |
| ------- | ----------------------------------------- |
| **이세진** | 인증 및 보안 체계 설계, 유스케이스 다이어그램 수합             |
| **이유정** | 관리자 기능 명세화, 유스케이스 상세 기술서(Descriptions) 수합 |
| **김동호** | 시스템 요구사항 정의서 수합, 사용자 편의 기능 분석             |
| **김채원** | 사용자 인터랙션 설계 및 UI 화면 수합, 형상 관리 및 프로젝트 제출   |



### 팀원별 상세 수행 내용
#### ① 이세진
- 회원 가입(1), 로그인(2), 로그아웃(3) 등 인증 시스템 관련 핵심 유스케이스의 논리 구조 설계
- 서비스 진입 과정에서 필요한 인증 및 보안 흐름 정의
- 전체 시스템 기능을 표현한 Use Case Diagram 수합 및 정리

#### ② 이유정
- 설문 등록(5), 설문 리스트 조회(6), 설문 응답 통계 조회(12) 등 관리자 기능 설계
- 데이터 관리 및 분석 프로세스 명세화
- 팀원들이 작성한 Use Case Description 문서 수합 및 통합 정리

#### ③ 김동호
- 회원 탈퇴(4), 설문 검색(7), 설문 상세정보 조회(8) 기능 요구사항 분석
- Requirement List 수합 및 기능별 요구사항 정리
- 프로젝트 개발 범위 및 기능 정의 문서 관리

#### ④ 김채원
- 설문 응답(9), 응답 조회 및 취소(10), 응답 수정(11) 등 사용자 참여 프로세스 설계
- 팀원들이 작성한 UI 화면 자료 수합 및 기능별 화면 구성 정리
- GitHub 기반 형상 관리 및 Git History(Log) 생성
- 최종 보고서 및 제출 문서 통합·검토 후 프로젝트 제출 진행
